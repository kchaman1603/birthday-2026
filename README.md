# Madam Ji Birthday Surprise Website

Romantic static website for 16 March birthday surprise.

## Features
- Background music toggle (`music.mp3`)
- Auto photo slideshow (every 2.5s)
- Floating hearts animation
- Relationship timeline section
- Gift box reveal message
- Love letter typing effect
- Secret message reveal
- Fireworks canvas effect
- Countdown to next 16 March

## Replace with your assets
1. Add your real song to `music.mp3`.
2. Replace files in `images/photo1.jpg` ... `images/photo5.jpg` (or extend the list in `script.js`).

## Run locally
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.

## Deploy to GitHub Pages
1. Push this repo to GitHub.
2. Open **Settings → Pages**.
3. Select branch (`main`) and root folder.
4. Save and share your generated URL.
